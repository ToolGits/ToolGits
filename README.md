# 🔎 Overview

**ToolGits** was created by **[enzobobdevvideos04-ctrl](https://github.com/enzobobdevvideos04-ctrl)** as an organization for building, experimenting with and publishing software.

Projects under ToolGits can use completely different languages, platforms and architectures.

```text
ToolGits
│
├── 📚 Toollibs
│   └── C++ Framework Ecosystem
│
├── ⚙️ ToolCL
│   └── Lightweight C99 Framework
│
└── 🤖 XeZenOn
    └── Android Kotlin Project
```

The projects are **independent repositories**. ToolGits provides the organizational home rather than a shared technical architecture.

# 🚀 Projects

## 📚 Toollibs

> **Modular C++ framework ecosystem**

Toollibs is a modular C++ framework ecosystem focused on reusable libraries, native development and cross-platform software.

> [!WARNING]
> **Toollibs is officially frozen.**
>
> Active development ended with **v4.4 — RebirthCatalyst** on **September 28, 2026**.
>
> The repository remains preserved with its source code, history and releases.

## ⚙️ ToolCL

> **Keep it small. Keep it portable. Keep it simple.**

ToolCL is a lightweight **C99 framework** focused on modular utilities, mathematics, logging, strings, vectors, matrices and optional 3D/OpenGL functionality.

| | |
|---|---|

| **License** | MIT |
| **Status** | 🟢 Stable |
