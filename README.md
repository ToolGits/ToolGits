# ToolGits 🛠️

> The official ToolGits organization showcase.

ToolGits is an open source organization focused on building software, frameworks, libraries, tools, experiments, and other technical projects.

## 🚀 About ToolGits

ToolGits brings together projects built around software development, experimentation, learning, and practical engineering.

The organization contains projects written in different programming languages and targeting different platforms, with each project having its own purpose, architecture, documentation, and license.

This repository serves as the central showcase for ToolGits projects.

## 📦 Projects

### 📚 Toollibs

Toollibs is a modular C++ framework ecosystem designed for building reusable libraries, development tools, and cross-platform applications.

It focuses on simplicity, scalability, native performance, modular systems, and extensible software architecture.

**Current version:** `v4.4 — RebirthCatalyst`

**Language:** C++

**Platforms:** Linux • Windows • Android

**License:** MIT

**Repository:**  
https://github.com/ToolGits/Toollibs/

---

### ⚙️ ToolCL

ToolCL is a lightweight framework written in C, focused on simplicity, portability, and modular development.

Its philosophy is:

> Keep it small, keep it portable, keep it simple.

**Current version:** `v0.3.0`

**Language:** C99

**Build system:** CMake

**License:** MIT

**Repository:**  
https://github.com/ToolGits/ToolCL/

---

### 🤖 XeZenOn

XeZenOn is a lightweight semi-AI project for Android focused on modular intelligence, local knowledge, language detection, intents, rules, responses, and conversational systems.

The project is designed to evolve gradually through modular systems rather than depending on a large external AI model.

**Current version:** `v1.1.1 — Stable`

**Language:** Kotlin

**Platform:** Android

**License:** MPL-2.0

**Repository:**  
https://github.com/ToolGits/XeZenOn/
